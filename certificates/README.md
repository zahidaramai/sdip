# `certificates/` — issued Equivalence Certificates

**This folder carries the project's whole argument.** SDIP's claim is that the product is
the file *plus the proof*; a certificate is the proof, and one is committed here so a
reader can check it before deciding whether any of this is worth their time.

## The reference certificate

[`465297171ccb-20260825T101250+0000.json`](./465297171ccb-20260825T101250+0000.json) — **`verdict: EQUIVALENT`**, `release_ready: true`, all seven gates
`PASS`, issued from a clean working tree.

| | |
|---|---|
| Source | synthetic poststack 3-D, **86,928 bytes**, 168 traces, 12 × 14 × 64 |
| SHA-256 | `465297171ccbf63f1f7f71ef0ccdec9f9a72dccc254673b7250706a624086b85` |
| Gates | `PPPPPPP` — G1 … G7 |
| G7 | 15 corruptions, each failing exactly its declared gates; 1 not applicable on a full grid |

## Reproduce it in about a minute

The fixture is **generated by committed code with a fixed seed**, so the digest above is
reproducible rather than asserted:

```python
# make_reference.py
from tests.fixtures.generators import make_poststack3d

if __name__ == "__main__":  # required: MDIO's parser uses a spawn context
    make_poststack3d("reference-poststack3d.sgy", n_inline=12, n_crossline=14, n_samples=64)
```

```bash
uv run python make_reference.py
sha256sum reference-poststack3d.sgy   # must match the digest above

uv run sdip certify reference-poststack3d.sgy reference.mdio \
    --rss-ceiling-gib 8.0 --wall-ceiling-s 1500 \
    --certificates certificates
```

## Check it without installing SDIP

**That is the point of publishing a schema.** The certificate is validated against
[`sdip-certificate-v0.schema.json`](../src/sdip/schema/sdip-certificate-v0.schema.json)
by any JSON Schema validator — SDIP is not involved:

```bash
pip install jsonschema
python -c "
import json, jsonschema
cert   = json.load(open('certificates/465297171ccb-20260825T101250+0000.json'))
schema = json.load(open('src/sdip/schema/sdip-certificate-v0.schema.json'))
jsonschema.validate(cert, schema)
print(cert['verdict'], cert['release_readiness']['release_ready'])
"
```

Installing the package carries the schema too, so a consumer who never clones this
repository still has the validator. **Not on PyPI** — install from a tag:
`pip install git+https://github.com/zahidaramai/sdip@v1.1.0`. PyPI is a support
commitment, not a checkbox, and an install instruction that 404s is worse than none.

## What is and is not committed here

**Synthetic sources get a committed certificate.** Their fixture is regenerable from this
repository, so the digest can be re-derived by anyone.

**Certificates issued against restricted survey data are not committed**, and neither is
the data (test-data policy). Their rows still appear in
[`EQUIVALENCE_LEDGER.md`](../EQUIVALENCE_LEDGER.md) carrying verdict, gate string,
SHA-256, byte count and commit, with the path reading `LOCAL-ONLY`. **A digest is not
data**, and withholding the row entirely would let the public record understate what the
engine has been shown to do.

**`source_path` records the issuing machine's absolute path.** That is provenance, not
identity — **the SHA-256 is the identity**, and it is what a reader should compare.
